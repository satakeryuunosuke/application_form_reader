# 塾向け受講確認票処理システム (Application Form Reader) `v1.15.6`

生徒・保護者から提出される期間講習（夏期・冬期・春期）および通常授業（前期・後期）、志望校別対策講座などの受講確認票・申込書をスキャンし、バーコード／QRコードとチェックボックスから自動集計・承認・管理を行う完全クライアントサイドWebアプリケーションです。

---

## 📌 主な特徴・セキュリティ方針

- **手動登録保存後の自動一覧復帰・確実な登録フロー（`v1.15.6`）**:
  - 手動登録画面（通常モード・講座選択モード共通）で登録を保存後、自動的に提出状況一覧画面へ戻る画面遷移へ統一。
  - 連続入力機能を撤去し、1件登録するごとに一覧で最新の提出・集計状況を即座に確認できる安心・確実な運用フローを実現。

- **講座選択モードにおける標準枠（「変更なし」「変更あり」）完全廃止（`v1.15.4`）**:
  - 志望校別対策講座などの講座選択モードにおいて、不要となる受講確認用の「変更なし」枠および「変更あり」枠をUI・データ構造から完全に廃止。
  - プロジェクト作成ウィザード、プロジェクト書式設定モーダル、スキャン画面書式設定モーダル、およびキャリブレーターのタブ・オーバーレイ・凡例から「変更なし」「変更あり」枠および復元ボタンを徹底的に除外。

- **受講確認時の標準枠（「変更なし」「変更あり」）誤削除防止（`v1.15.2`〜`v1.15.3`）**:
  - 受講確認モードのプロジェクト作成ウィザード、書式調整モーダル、および共通既定書式設定において、「変更なし」「変更あり」枠の削除ボタン（✕）を非表示化・削除ガードを設定。
  - キャリブレーション画面のガイドバナーから不要な削除案内文言を撤去し、受講確認票に必須となる基本2枠の誤削除事故を確実に防止。

- **新規プロジェクト作成ウィザードのモード別UI最適化（`v1.15.1`）**:
  - 新規プロジェクト作成時、「受講確認モード（夏期・冬期・通常授業）」選択時には不要な志望校別講座追加パネルを排除し、従来のシンプルで直感的な受講確認票書式設定・位置調整画面へ復元。
  - 「講座選択モード（志望校別）」選択時のみ講座名×受講方法や自由項目の追加パネルを有効化し、目的別の迷いのないプロジェクト作成フローを実現。

- **管理ダッシュボードでの共有フォルダ格納名（`proj_...`）確認・ワンクリックコピー**:
  - 管理ダッシュボード上部に、共有フォルダ内やWindowsエクスプローラー上で本プロジェクトが保存されているフォルダ名（プロジェクトID `proj_...`）とパス目安を常時表示。
  - ワンクリックでクリップボードにコピーできるボタンを完備し、ファイルサーバー上でのフォルダ特定やバックアップ確認をスムーズ化。
  - 設定・メンテナンスカード（共有フォルダ最新同期／再書き出し）にも対象フォルダ名を明記。

- **読取コード規格切替（QRコード / CODE 39 / 自動判別）**:
  - Wordの差し込み印刷（`MERGEBARCODE`）で手軽に作成できる「QRコード」に完全対応。省スペース・傾きや汚れに強く、読取処理が高速化。
  - システム設定画面から「QRコード」「バーコード (CODE 39)」「自動判別（両対応）」をワンクリックで切り替え可能。LAN共有フォルダ経由で全PCに一括同期。
  - QRコードのFinder Patternから高精度な傾き角度と中心座標を算出し、チェックボックスの回転追従と位置合わせを実現。

- **志望校別対策講座「講座選択モード」のスキャン読取＆手動入力最適化**:
  - **スキャン読取**: PDFだけでなく、卓上スキャナーやスマホ等からの画像（JPEG / PNG）の複数一括ドロップ読取に対応。左ペインプレビューでの各講座マーク枠ハイライト、右ペインでのマーク検出バッジ（✅ マーク検出 / ⬜ 未選択）および全選択・全解除・形式別（Zoom/対面/動画）クイックボタン完備。
  - **手動登録**: 日能研番号入力＋Enterキーでの即座生徒確定、講座リストの形式別グループタグ表示などを備え、窓口・電話での受付もスムーズに登録可能。
- **志望校別対策講座「講座選択モード」の新設・特化（カタログ選択型）**:
  - 従来の「変更なし／あり」二者択一ではなく、日程・志望校・受講形式（Zoom・動画・校舎）が提示された講座ラインナップから希望講座を複数選んで申し込む「ショッピング方式」に完全特化。
  - スキャン確認・手動登録・照合画面で不要な「変更なし／あり」選択肢を一切排除し、選択中講座数カウンターや講座別バッジ一覧をリアルタイム連動。
  - プロジェクトダッシュボードに「講座別申込人数サマリー」および受講形式別（Zoom/動画/校舎）内訳を集計表示。
  - Excel (.xlsx) / CSV 出力では、生徒別一覧に加えて生徒（行）×全講座（列）のクロス集計マトリクスシートを自動出力。
- **完全クライアントサイド（オフライン動作可能）**:
  - 全ての画像処理・バーコード読取・データ保存（IndexedDB）をブラウザ内で完結。
  - 個人情報を扱うため、**外部サーバーへの通信は一切行いません**。
- **標準枠の固定保護 & 志望校別対策講座の自由なカスタマイズ**:
  - 受講確認票の基本書式に合わせて、標準の「変更なし」「変更あり」チェックボックスは誤削除防止のため固定保護。
  - 設定画面で「講座名（名古屋Ⅰ、東海Ⅰなど）」と「受講方法（Zoom授業、御器所校など）」をそれぞれマスタとして登録・管理。LAN共有フォルダ経由で全PC間で自動同期。
  - プロジェクト作成ウィザード（ステップ3）や書式設定画面にて、マスタのプルダウンから「講座名×受講方法」を組み合わせてチェックボックス枠を即座に追加・削除・位置調整可能。
  - 自由記述による任意のカスタムチェックボックスも追加でき、自動読み取り・照合・特記事項バッジ表示・集計までシームレスに連動。
- **完了（アーカイブ）退避・ワンクリック復元 & 共有フォルダ一括削除**:
  - 講習終了時にプロジェクトを「完了（アーカイブ）」に設定すると、共有フォルダの退避フォルダ（`archive/`）へ自動移動。
  - 全端末のIndexedDBおよびホーム画面から自動削除され、日常作業時の走査速度とブラウザ容量を常に軽量・高速に維持。
  - ホーム画面の「完了済みのプロジェクト」ボタンからいつでも進行中に復元可能。
  - 設定画面から「昨年度」「一昨年度以前」など年度単位で一括選択し、対象一覧を確認の上で共有フォルダから安全に完全物理削除可能。
- **共有フォルダ書き込み信頼性・パーミッション管理の徹底強化**:
  - 一時ファイル（`_tmp_`）経由の2段階アトミック書き込み、自動リトライ（最大3回・指数バックオフ）、書き込み後ベリファイ検証を実装。通信途絶による0バイト空ファイル破損を防止。
  - プロジェクト管理画面からワンクリックで実行できる「共有フォルダへ再書き出し」復旧機能を搭載。ブラウザ再起動等による権限一時停止時も自動再認可（User Activation）により安全・確実に書き出しを復旧可能。
  - ヘッダー・ホーム・設定画面での「共有フォルダ再開」ワンクリック認可機能により、日々の運用負荷を極小化。
- **GitHub Pages での無料ホスティング**:
  - 静的サイトとして配信可能。サーバー費用ゼロ。
- **バーコードアンカー相対座標読取**:
  - CODE 39 バーコードを基準点としてチェックボックス位置を特定するため、スキャナーのセット位置のずれ（±2cm程度）を自動吸収。
- **汎用プロジェクト設計**:
  - プログラミング知識不要。実施年（PC自動取得）・学年（1〜6年）・講習名（夏期・冬期・春期・前期・後期・志望校別対策講座、および「その他」自由記述）を選択・入力し、CSVを読み込ませるだけで誰でも新規プロジェクトを作成可能。
- **ファイルサーバー通信遅延対策 & 連打防止**:
  - LAN共有フォルダとの低速通信時でも、画面全体の高品質ローディングオーバーレイとボタン内スピナーで状況を明示。
  - 排他制御（Mutex）およびボタン自動無効化により、二重クリックや連打によるデータ競合・多重同期を完全防止。
