# 塾向け受講確認票処理システム (Application Form Reader) `v1.23.1`

生徒・保護者から提出される期間講習（夏期・冬期・春期）および通常授業（前期・後期）、志望校別対策講座などの受講確認票・申込書をスキャンし、バーコード／QRコードとチェックボックスから自動集計・承認・管理を行う完全クライアントサイドWebアプリケーションです。

---

## 📌 主な特徴・セキュリティ方針

- **受講確認モードの読取精度・二者択一判定ロジック改善（`v1.23.1`）**:
  - **二者択一の大小比較判定**: 受講確認モード（変更なし／変更あり）において、固定しきい値の論理積判定（`isChecked && !isChecked`）から、両枠の黒画素率（充填率）の大小比較ロジックへ刷新。印刷枠線の黒インクやわずかな影・かすれによる誤読（変更ありにチェックがあるのに変更なしと判定される問題等）を完全解消。
  - **書式設定・スキャン時座標ズレの解消**: 外枠下端罫線（下端線補正）の基準距離（`refQrToBorderDist`）が書式設定画面での調整中と保存後で食い違い、スキャン時に枠が上下にズレて外れてしまう不具合を修正。キャリブレーション中は常に基準スケール（1.0）で編集・プレビューし、用紙高さに対する比率（`refQrToBorderRatio`）による正規化で解像度（DPI）の違いも吸収。
  - **スキャン画面での書式保存時即時再計算**: スキャン画面の「📐 書式調整」モーダルで設定を保存した際、保留中のスキャンキュー全体を即座に再評価し、画面上の判定バッジ・オーバーレイプレビューを最新の正しい結果へリアルタイム更新。
  - **キャリブレーター総合自動判定バッジ表示**: 書式設定画面において、受講確認モード時の二者択一判定結果（「✅ 変更なし (所属受講)」／「⚠️ 変更あり (受講変更)」）を明示。

- **受講確認モード「変更有」選択肢への「他教室で受講」追加 ＆ プロジェクト管理ダッシュボードでの自由追加・設定（`v1.23.0`）**:
  - 受講確認モードの「変更あり」選択肢に「他教室で受講」を標準追加。
  - プロジェクトの管理ダッシュボードに「🏷️ 変更有の選択肢設定」管理カードを新設。校舎や講習の運用に合わせて、特別受講形態（例: 「他教室で受講」「Zoom受講」「個別併用」「辞退」など）をモーダルから自由に追加・並び替え（▲/▼）・削除・初期化可能。
  - 手動登録画面、スキャン読取・承認画面、スキャン照合・確認画面、提出状況一覧の「確定後クラス」フィルター、および履歴タイムラインすべてにリアルタイム連動。
  - 共有フォルダ（File System Access API）の `meta.json` にも自動保存・双方向同期され、校舎内の複数端末間で同一の選択肢設定を即座に共有。

- **プロジェクト画面ヘッダーの表示最適化・折り返し防止（`v1.22.2`）**:
  - プロジェクト詳細画面のヘッダーにおいて、バッジの増加や画面幅によってタイトルや操作ボタン（管理ダッシュボード等）が下段に折り返してしまう問題を解消。
  - 1行目に「プロジェクトタイトル＋主要ステータスバッジ（進行中・同期状態・講座選択モード）」、2行目に「属性バッジ（年度・学年・期）＋生徒数・講座数集計サマリー」をすっきりと整理。
  - 右側の操作ボタン群（更新、手動登録・変更、管理ダッシュボード）を横一列に固定し、中途半端な折り返しを完全防止。

- **プロジェクト切り替え時・スキャン承認完了時の状態管理・クリーンアップ適正化（`v1.22.1`）**:
  - スキャン承認完了画面や処理中のスキャンキューが、別プロジェクトへ画面遷移した際にも残存・表示されてしまう不具合を修正。
  - プロジェクト変更時および承認完了画面からの離脱時にスキャンキューおよび表示状態を確実に初期化し、プロジェクト間での状態混在・情報漏洩を完全防止。
  - スキャン照合・提出状況一覧・手動登録画面においても、プロジェクト切り替え時に古い検索ワードやフィルタ・選択状態が引き継がれないようクリーンアップを徹底。

- **チェックボックスマスの大きさ全選択肢自動同期（`v1.22.0`）**:
  - チェックボックス設定（キャリブレーション）画面において、マスの大きさ（正方形サイズ）を調整する際、すべての選択肢（変更なし、変更あり、志望校別対策講座などのカスタム枠すべて）のマスの大きさが自動で同期されるよう改善。
  - 枠の大きさが選択肢ごとに不揃いになることで黒画素割合（判定面積比率）の基準にブレが生じる問題を防ぎ、全項目で均一かつ精度の高いマーク判定を実現。
  - スライダー操作、微調整ボタン（➖ / ➕）、新規枠追加のいずれにおいても自動的に共通サイズが連動・維持されます。

- **講座選択モードのスキャン読取最適化・選択講座優先表示（`v1.21.0`）**:
  - 志望校別対策講座（講座選択モード）のスキャン読み取り承認画面において、用紙に多数の講座（20〜34講等）がある場合でも、マーク検出された選択講座を自動的にリスト最上部に優先配置（安定ソート）。
  - スクロール不要で選択された講座を一目で確認・承認可能。
  - クイック操作ツールバーに「🔝 選択中を上へ」再整列ボタンを新設し、手動トグル後もワンクリックでいつでも再整列可能。
  - スキャン照合レビュー画面（`review.js`）でも同様に選択講座を上部へ優先表示。

- **スキャン照合画面の左右矢印キー操作の不具合修正（`v1.20.2`）**:
  - キーボードイベントリスナーの重複登録を完全解消し、単一リスナー管理とキー長押し（オートリピート）防止ガードを実装。
  - 矢印キー（`←` / `→`）を1回押すごとに、確実に前後の登録データへ1件ずつ軽快に切り替わるよう修正。

- **スキャン照合画面の「変更・承認タイムライン」表示（`v1.20.1`）**:
  - 右ペインに「変更・承認タイムライン」を実装。最新の確定内容とその場での修正フォーム、および過去の変更・承認履歴（初回スキャン、電話連絡等）を時系列カードで一覧表示。
  - 原票画像（左ペイン）と突き合わせながら、過去の経緯を確認しつつ最新の受講内容を即座に修正・保存可能。

- **スキャン照合・登録履歴確認機能の刷新（`v1.20.0`）**:
  - 承認・未承認ステータス管理（「照合OK」「不一致あり」ボタン、進捗バー、未確認フィルター等）を撤廃。
  - スキャン原票画像と登録データを左右2ペインで並べ、キーボードの左右矢印キー（`←` / `→`）やボタンで前後の登録レコードを軽快に切り替えながら閲覧。
  - 修正フォームを常時展開し、画像を見ながら間違っている項目（受講判定、受講クラス、受講科目、講座チェック、備考等）があればその場で即座に編集・保存（IndexedDB更新 ＆ 共有同期）できるシームレスなUIへ刷新。
  - 特定の生徒へ直接飛べるクイックジャンプ移動セレクタを完備。

- **外枠罫線検出の高精度化・最下部文章行の誤検出防止（`v1.19.1`）**:
  - スキャナーのかすれや帳票最下部の印字文章（注意事項・注記テキスト等）が存在する場合でも、文章行を外枠罫線と誤認しない**多段階フィルタ（局所水平ラン長検証 ＋ 水平帯域黒ピクセル充填率検証 ＋ RANSACインライアXスパン検証）**を搭載。
  - 短い画の連続である文章行を確実にスキップし、かすれた本物の水平外枠罫線まで継続走査して捉えることで、傾き補正および縦スケーリングの安定性を飛躍的に向上。

- **画面遷移高速化 ＆ 待機モーション（`v1.19.0`）**:
  - 共有フォルダ同期（File System Access API）による画面遷移のブロッキングを完全解消。ローカルIndexedDBから即座に画面を描画し、同期処理はバックグラウンド非同期で実行。
  - 同一プロジェクト内のタブ切り替え（提出一覧／手動登録／管理ダッシュボード等）でヘッダーの全再描画を省略し、タブ中身のみを即座に差し替えることでちらつきと遷移待ちをゼロ化。
  - 30秒間TTLのスマート同期スロットル機構により、同一画面への連続遷移やタブ往復時の重複I/Oアクセスを完全抑止。手動「🔄 更新」ボタン押下時はキャッシュを破棄して最新データを強制取得。
  - 待機モーションとして、シマー付きスケルトンローダー、パルスドット同期インジケーター、差分反映通知バーを装備。

- **志望校別対策講座（全34講対応）キャリブレーションUI刷新・並び替え機能（`v1.18.0`）**:
  - 全34講など多数のチェックボックスが存在する場合でも右ペインが縦横に肥大化しない洗練された「スマート枠セレクタ（ドロップダウン ＋ 前後ナビ ＋ 現在位置）」へ刷新。
  - リアルタイム判定カードを選択中枠ハイライト表示および全件アコーディオン展開式にコンパクト化し、微調整スライダーがいつでもスクロールなしで即操作可能。
  - キャリブレーション画面、プロジェクト作成ウィザード、詳細画面、スキャン画面の読取項目管理パネルにて、項目の上下移動（▲/▼）、名前順一括ソート（🔤）、リアルタイム絞り込み検索を実装。
  - システム設定の「講座名マスタ」でも順序移動（◀/▶）および名前順ソートに対応。

- **まとめてPDFスキャン時の一括バックグラウンドアップロード（`v1.17.0`）**:
  - 大量スキャン承認時のLAN共有フォルダ通信待ちをゼロ化。スキャン作業中はローカルIndexedDB（未送信キュー）に高速保存（バッチモード）。
  - 一連の確認票承認作業が完了した後に、バックグラウンドでまとめて共有フォルダへ安全にアップロード（差分イベント書き出し）。
  - アップロードはバックグラウンド非同期タスクとして実行されるため、完了画面から待たずに提出状況一覧や別業務へ即座に遷移可能。
  - 完了画面およびヘッダーインジケーターにリアルタイム進捗状況（`送信中: N / M 件`、プログレスバー、完了通知）を分かりやすく表示。

- **【パターンA】外枠罫線アシスト補正エンジン（`v1.16.0`）**:
  - A4縦全体など長距離にチェックボックスが配置される帳票において、用紙下部（表の最下端や囲み罫線）の水平罫線をRANSACロバストアルゴリズムにより自動検出。
  - 約1,000〜1,600ピクセルの超長基線長を活かして**0.05度以下の超高精度な傾き補正**と、スキャナの余白裁断ブレを完全吸収する**縦スケーリング補正**を実現。QRコードから離れたA4最下部でもピタッとチェック枠を捉えます。
  - キャリブレーション画面およびスキャン結果プレビューに検出された外枠線を水色ラインで可視化。外枠線がない帳票でも従来の水平固定へ安全に自動フォールバック。

- **QRコード読取時の傾き補正無効化（水平固定）（`v1.15.8`）**:
  - A4縦全体など長距離にチェックボックスが配置される帳票において、QRコードのファインダパターン微小検出ノイズ（0.5°〜1°程度）がテコの原理（レバーアーム効果）によって下部で大きな横ズレを引き起こす現象を防止。
  - QRコード読取時の角度補正を無効化（水平固定: `angle = 0`）し、QRコード中心位置（アンカー）のみに正確に追従する高精度・高安定な座標変換を実現。

- **チェックボックス座標調整範囲の大幅拡張（用紙全域対応）（`v1.15.7`）**:
  - チェックボックス位置キャリブレーションにおいて、左右位置（`dx`）および上下位置（`dy`）の調整可能範囲を用紙全域（`-100%` 〜 `+100%`）へ大幅拡張。
  - バーコードの位置によらず用紙内のあらゆる領域（上部・下部・左右端など）にチェックボックス判定枠を自由に配置可能。正方形サイズ（`size`）も `0.5%` 〜 `15.0%` に拡張。
  - 微調整ボタン（◀ ▶ ▲ ▼ ➖ ➕）にも範囲ガードを実装し、確実で安全な位置調整を実現。

- **手動登録保存後の自動一覧復帰・確実な登録フロー（`v1.15.6`）**:
  - 手動登録画面（通常モード・講座選択モード共通）で登録を保存後、自動的に提出状況一覧画面へ戻る画面遷移へ統一。
  - 連続入力機能を撤去し、1件登録するごとに一覧で最新の提出・集計状況を即座に確認できる安心・確実な運用フローを実現。

- **講座選択モードにおける標準枠（「変更なし」「変更あり」）完全廃止（`v1.15.4`）**:
  - 志望校別対策講座などの講座選択モードにおいて、不要となる受講確認用の「変更なし」枠および「変更あり」枠をUI・データ構造から完全に廃止。
  - プロジェクト作成ウィザード、プロジェクト書式設定モーダル、スキャン画面書式設定モーダル、およびキャリブレーターのタブ・オーバーレイ・凡例から「変更なし」「変更あり」枠および復元ボタンを徹底的に除外。

- **受講確認時の標準枠（「変更なし」「変更あり」）誤削除防止（`v1.15.2`〜`v1.15.3`）**:
  - 受講確認モードのプロジェクト作成ウィザード、書式調整モーダル、および共通既定書式設定において、「変更なし」「変更あり」枠の削除ボタン（✕）を非表示化・削除ガードを設定。
  - キャリブレーション画面のガイドバナーから不要な削除案内文言を撤去し、受講確認票に必須となる基本2枠の誤削除事故を確実に防止。

- **新規プロジェクト作成ウィザードのモード別UI最適化（`v1.15.1`）**:
  - 新規プロジェクト作成時、「受講確認モード（夏期・冬期・通常授業）」選択時には不要な志望校別講座追加パネルを排除し、従来のシンプルで直感的な受講確認票書式設定・位置調整画面へ復元。
  - 「講座選択モード（志望校別）」選択時のみ講座名×受講方法や自由項目の追加パネルを有効化し、目的別の迷いのないプロジェクト作成フローを実現。

- **管理ダッシュボードでの共有フォルダ格納名（`proj_...`）確認・ワンクリックコピー**:
  - 管理ダッシュボード上部に、共有フォルダ内やWindowsエクスプローラー上で本プロジェクトが保存されているフォルダ名（プロジェクトID `proj_...`）とパス目安を常時表示。
  - ワンクリックでクリップボードにコピーできるボタンを完備し、ファイルサーバー上でのフォルダ特定やバックアップ確認をスムーズ化。

- **読取コード規格切替（QRコード / CODE 39 / 自動判別）**:
  - Wordの差し込み印刷（`MERGEBARCODE`）で手軽に作成できる「QRコード」に完全対応。省スペース・傾きや汚れに強く、読取処理が高速化。
  - システム設定画面から「QRコード」「バーコード (CODE 39)」「自動判別（両対応）」をワンクリックで切り替え可能。LAN共有フォルダ経由で全PCに一括同期。

- **志望校別対策講座「講座選択モード」のスキャン読取＆手動入力最適化**:
  - **スキャン読取**: PDFだけでなく、卓上スキャナーやスマホ等からの画像（JPEG / PNG）の複数一括ドロップ読取に対応。左ペインプレビューでの各講座マーク枠ハイライト、右ペインでのマーク検出バッジ（✅ マーク検出 / ⬜ 未選択）および全選択・全解除・形式別（Zoom/対面/動画）クイックボタン完備。
  - **手動登録**: 日能研番号入力＋Enterキーでの即座生徒確定、講座リストの形式別グループタグ表示などを備え、窓口・電話での受付もスムーズに登録可能。
- **志望校別対策講座「講座選択モード」の新設・特化（カタログ選択型）**:
  - 従来の「変更なし／あり」二者択一ではなく、日程・志望校・受講形式（Zoom・動画・校舎）が提示された講座ラインナップから希望講座を複数選んで申し込む「ショッピング方式」に完全特化。
  - スキャン確認・手動登録・照合画面で不要な「変更なし／あり」選択肢を一切排除し、選択中講座数カウンターや講座別バッジ一覧をリアルタイム連動。
  - プロジェクトダッシュボードに「講座別申込人数サマリー」および受講形式別（Zoom/動画/校舎）内訳を集計表示。
  - Excel (.xlsx) / CSV 出力では、生徒別一覧に加えて生徒（行）×全講座（列）のクロス集計マトリクスシートを自動出力。
- **完全クライアントサイド（オフライン動作可能）**:
  - 全ての画像処理・バーコード読取・データ保存（IndexedDB）をブラウザ内で完結。
  - 個人情報を扱うため、**外部サーバーへの通信は一切行いません**。
- **標準枠の固定保護 & 志望校別対策講座の自由なカスタマイズ**:
  - 受講確認票の基本書式に合わせて、標準の「変更なし」「変更あり」チェックボックスは誤削除防止のため固定保護。
  - 設定画面で「講座名（名古屋Ⅰ、東海Ⅰなど）」と「受講方法（Zoom授業、御器所校など）」をそれぞれマスタとして登録・管理。LAN共有フォルダ経由で全PC間で自動同期。
  - プロジェクト作成ウィザード（ステップ3）や書式設定画面にて、マスタのプルダウンから「講座名×受講方法」を組み合わせてチェックボックス枠を即座に追加・削除・位置調整可能。
  - 自由記述による任意のカスタムチェックボックスも追加でき、自動読み取り・照合・特記事項バッジ表示・集計までシームレスに連動。
- **完了（アーカイブ）退避・ワンクリック復元 & 共有フォルダ一括削除**:
  - 講習終了時にプロジェクトを「完了（アーカイブ）」に設定すると、共有フォルダの退避フォルダ（`archive/`）へ自動移動。
  - 全端末のIndexedDBおよびホーム画面から自動削除され、日常作業時の走査速度とブラウザ容量を常に軽量・高速に維持。
  - ホーム画面の「完了済みのプロジェクト」ボタンからいつでも進行中に復元可能。
  - 設定画面から「昨年度」「一昨年度以前」など年度単位で一括選択し、対象一覧を確認の上で共有フォルダから安全に完全物理削除可能。
- **共有フォルダ書き込み信頼性・パーミッション管理の徹底強化**:
  - 一時ファイル（`_tmp_`）経由の2段階アトミック書き込み、自動リトライ（最大3回・指数バックオフ）、書き込み後ベリファイ検証を実装。通信途絶による0バイト空ファイル破損を防止。
  - プロジェクト管理画面からワンクリックで実行できる「共有フォルダへ再書き出し」復旧機能を搭載。ブラウザ再起動等による権限一時停止時も自動再認可（User Activation）により安全・確実に書き出しを復旧可能。
  - ヘッダー・ホーム・設定画面での「共有フォルダ再開」ワンクリック認可機能により、日々の運用負荷を極小化。
- **GitHub Pages での無料ホスティング**:
  - 静的サイトとして配信可能。サーバー費用ゼロ。
- **バーコードアンカー相対座標読取**:
  - CODE 39 バーコードを基準点としてチェックボックス位置を特定するため、スキャナーのセット位置のずれ（±2cm程度）を自動吸収。
- **汎用プロジェクト設計**:
  - プログラミング知識不要。実施年（PC自動取得）・学年（1〜6年）・講習名（夏期・冬期・春期・前期・後期・志望校別対策講座、および「その他」自由記述）を選択・入力し、CSVを読み込ませるだけで誰でも新規プロジェクトを作成可能。
- **ファイルサーバー通信遅延対策 & 連打防止**:
  - LAN共有フォルダとの低速通信時でも、画面全体の高品質ローディングオーバーレイとボタン内スピナーで状況を明示。
  - 排他制御（Mutex）およびボタン自動無効化により、二重クリックや連打によるデータ競合・多重同期を完全防止。
