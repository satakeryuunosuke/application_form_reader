# 塾向け受講確認票処理システム (Application Form Reader) `v1.1.0`

生徒・保護者から提出される期間講習（春期・夏期・冬期）の受講確認票・申込書をスキャンし、バーコードとチェックボックスから自動集計・承認・管理を行う完全クライアントサイドWebアプリケーションです。

---

## 📌 主な特徴・セキュリティ方針

- **完全クライアントサイド（オフライン動作可能）**:
  - 全ての画像処理・バーコード読取・データ保存（IndexedDB）をブラウザ内で完結。
  - 個人情報を扱うため、**外部サーバーへの通信は一切行いません**。
- **GitHub Pages での無料ホスティング**:
  - 静的サイトとして配信可能。サーバー費用ゼロ。
- **バーコードアンカー相対座標読取**:
  - CODE 39 バーコードを基準点としてチェックボックス位置を特定するため、スキャナーのセット位置のずれ（±2cm程度）を自動吸収。
- **汎用プロジェクト設計**:
  - プログラミング知識不要。実施年（PC自動取得）・学年（1〜6年）・講習名をプルダウン選択し、CSVを読み込ませるだけで誰でも新規プロジェクトを作成可能。
