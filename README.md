# 塾向け受講確認票処理システム (Application Form Reader) `v1.29.0`

生徒・保護者から提出される期間講習（夏期・冬期・春期）、新年度の継続確認、志望校別対策講座などの受講確認票・申込書をスキャンし、バーコード／QRコードとチェックボックスから自動集計・承認・管理を行う完全クライアントサイドWebアプリケーションです。

---

## 📌 主な特徴・セキュリティ方針

- **スキャン読取画面の判定デバッグモード（黒画素率・詳細測定値の可視化）（`v1.29.0`）**:
  - スキャン読み取り画面（承認ビュー）に「🐞 デバッグ: ON/OFF」切替トグルを実装。
  - **画像上への黒画素率ラベルのダイレクト印字**: 左ペインプレビュー画像および全画面拡大表示（⛶）において、受講する枠・その他枠・4科目枠・2科目枠・カスタム項目枠の各位置の上に測定された黒画素率（%）を高コントラスト背景バッジで直接描画。画面や用紙の撮影時にどこが何％と判定されたか一目瞭然に把握可能。
  - **右ペインの詳細デバッグカード ＆ インラインバッジ**: 科目数（4科枠 vs 2科枠の黒画素率および差分%・優位判定）、継続確認（受講枠 vs その他枠）、学年別項目、コード検知・下端罫線補正の数値を一覧表示。
  - 照合レビュー画面での再確認用として提出レコードに `scanCheckResult` を連動保存。

- **日能研番号チェックデジット機能（13の倍数検証）の廃止（`v1.28.1`）**:
  - 日能研番号の下4桁（個人固有番号）が13の倍数であるかを検証していた従来のチェックデジット判定を廃止。
  - 校舎コード2桁＋生徒区分（N/A）＋学年（1〜6）＋4桁数字のフォーマット検証へ移行し、13の倍数以外の固有番号を持つ生徒データもエラーとならず正常に受領・登録・CSV取込できるよう改修。

- **講座選択モードの動的2グループ適応判定 ＆ 訂正塗りつぶし外れ値の非受講処理（`v1.28.0`）**:
  - **用紙濃淡（全体的に白／黒）への動的2群適応**: 従来の固定閾値（25%）では対応が難しかったコントラストが淡いスキャン（薄いペン）や暗いスキャン（裏写り・影・枠線の太さ）に対し、大津の判別分析法（1次元2クラスタリング）を導入。同一用紙内の全講座チェックボックスから「チェックなし群」と「チェックあり群」の最適境界しきい値を自動算出・適応判定。
  - **誤記入・訂正塗りつぶし外れ値の自動検知＆非受講判定**: 間違えてチェックした後にペンでぐちゃぐちゃに塗りつぶした枠（過剰黒画素・外れ値）を自動検知し、ユーザーの意図通り「非受講」として安全に処理。外れ値による他の正常枠のしきい値計算歪みも完全防止。全項目塗りつぶしの場合は通常通り受講判定。
  - **全件未記入セーフティガード**: 2群間の平均差・境界ギャップが微小な均一用紙（全件未受講・0講座申込）での誤検出を二重防止。
  - **キャリブレーション ＆ 照合レビュー画面での可視化**: 算出された動的閾値（`🎯 動的適応: 閾値 XX%`）や訂正塗りつぶし（`⚠️ 訂正取消`）を各画面で明示バッジ表示。

- **クライアントサイドWebセキュリティ開発規約の策定（`v1.27.6`）**:
  - 本リポジトリおよび今後の完全クライアントサイド型Webアプリケーション開発において、CSP導入、DOM-based XSS防御、CSV/Excel数式インジェクション対策、プロトタイプ汚染防御、サードパーティライブラリ安全運用の「5大脆弱性対策」を標準プラクティスとして明文化・運用規約化（`AGENTS.md` およびグローバルルールへ登録）。

- **セキュリティ強化（Content Security Policy (CSP) 設定 ＆ バックアップJSONインポート検証）（`v1.27.5`）**:
  - **Content Security Policy (CSP) による外部送信・悪意あるリソース読み込みのブラウザレベル強制遮断**: `<meta http-equiv="Content-Security-Policy">` を定義。許可されていない外部ドメインへの Fetch/XHR/WebSocket 送信を完全に遮断し、万一のスクリプト混入時にも生徒の個人情報やフォームデータが外部へ送信されるリスクをゼロに抑制。PDF.jsのWorker・Blob処理、Google Fonts等の安全なリソースのみを過不足なくホワイトリスト許可。
  - **バックアップJSONインポート時のスキーマ検証・プロトタイプ汚染防御**: システム設定画面からのバックアップ復元（`importFullBackup`）時、入力データ構造の厳格な検証を実施。各テーブル配列内のオブジェクトから `__proto__`, `constructor`, `prototype` キーを完全に除去・無害化し、不正ファイル読み込みによるシステム誤作動・プロトタイプ汚染を防御。

- **ローカル検証サーバー（server.py）の非公開化・Git追跡除外（`v1.27.4`）**:
  - 本番運用（GitHub Pages）では一切不要である開発・検証用スクリプト `server.py` をリモートリポジトリ（Git追跡）から完全除外・`.gitignore` に登録。
  - 公開リポジトリへの露出リスクを遮断しつつ、ローカル環境での手元検証用ファイルとしてはそのまま保持。

- **セキュリティ強化（CSV/Excel数式インジェクション対策 ＆ 共有同期イベント検証）（`v1.27.3`）**:
  - **CSV / Formula Injection（数式インジェクション）の防御**: 生徒名、日能研番号、クラス、講座名、特記事項などのデータ出力時、先頭文字が `=`, `+`, `-`, `@`, タブ, 改行で始まる悪意ある入力値に対し、シングルクォートプレフィックス（`'`) を自動付与してプレーンテキスト化。Excelやスプレッドシート開封時の不正コマンド・外部通信マクロ実行を防止。
  - **共有フォルダ同期イベントの厳格なスキーマ検証・サニタイズ**: LAN共有フォルダ経由で受信する JSON イベントファイルに対し、イベントID、アクション種別、タイムスタンプ範囲、プロトタイプ汚染プロパティ（`__proto__`, `constructor`）の除外、データオブジェクトの型検証を実施。
  - **同期リプレイ時の全運用モードフィールド完全同期**: 複数端末間でのイベントリプレイ時、継続確認モードの受講可否・学年別項目、講座選択モードの選択講座データ、照合ステータスを漏れなく確実に同期反映。

- **セキュリティ脆弱性対策（XSS防御およびPDF.js任意コード実行の無効化）（`v1.27.2`）**:
  - **DOM-based / Stored XSSの完全防御**: 全画面（提出状況一覧、スキャン照合レビュー、スキャン読取・承認、手動登録、プロジェクト管理・生徒一覧、設定画面、トースト・確認モーダル・画像ライトボックス）における動的HTML出力に `escapeHtml` サニタイズ処理を徹底適用。生徒名、日能研番号、クラス、講座名、特記事項、担当者名などの不正文字列やスクリプト注入リスクを無害化。
  - **PDF.js CVE-2024-4367 任意コード実行脆弱性の防御**: フォント描画時の動的コード評価パスを遮断するため、PDFドキュメント読み込みオプションに `isEvalSupported: false` を明示指定。悪意ある細工が施されたPDFファイルによるスクリプト実行リスクを防止。
  - **画像ライトボックスのプロトコル検証**: `javascript:` 等の危険なスキームを遮断し、`data:image/` や `blob:` 等の安全な画像ソースのみをプレビュー表示するよう防御を強化。
