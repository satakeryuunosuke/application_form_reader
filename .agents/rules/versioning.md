# バージョン管理ルール

本リポジトリで機能追加、UI改善、不具合修正等の改修を実施した際は、必ずセマンティックバージョニングに基づいてバージョンを引き上げてください。

## バージョン採番基準
- **PATCH (例: v1.3.0 → v1.3.1)**: バグ修正、軽微なUI・スタイル微調整、文言修正など
- **MINOR (例: v1.3.0 → v1.4.0)**: 新機能追加、画面・同期・集計機能の拡張など
- **MAJOR (例: v1.3.0 → v2.0.0)**: 破壊的変更、DB大刷新など

## 更新対象ファイル
改修完了時、以下のファイルを更新すること：
1. `js/version.js`: `APP_VERSION` および `APP_BUILD_DATE`（当日日付 YYYY-MM-DD）
2. `index.html`: `#header-app-version` の表記
3. `README.md`: 1行目のバージョン表記
4. `CONCEPT_DESIGN.md`: 必要に応じてタイトルバージョン更新
